# LocalDrop Support

LocalDrop transfers selected files directly between devices, without an account or developer cloud file server. It is an iPhone and iPad app. Browser receiving on Mac, Windows and Android requires the same private Wi-Fi network and a temporary local HTTPS session approved on the iPhone.

## Getting started

1. Open LocalDrop on both Apple devices and choose Send / Receive.
2. Select your files and device. Confirm the connection and compare the security code on both devices.
3. Approve the file offer, keep both apps open and wait for completion.

For browser receiving, choose the browser option on the sending iPhone and open its QR code or local address on the receiving device. Compare the certificate fingerprint before proceeding through any certificate warning. Browser receiving supports up to 256 MB per file and 512 MB per batch. Save each file and confirm receipt. Browser uploads to iPhone are not included.

Guest Wi-Fi, client isolation, VPNs and backgrounding can prevent local transfers. Try a private Wi-Fi network and allow Local Network access in iOS Settings. Full-screen ads may appear after successful transfers; file transfer remains available without Internet or ads.
